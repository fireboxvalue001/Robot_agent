# VD10 说明书导入

本机测试：关闭已有服务，运行 `start-demo.bat`，打开 `http://127.0.0.1:8877`。脚本启用仅限直连本机的免令牌模式，并关闭代理头信任。不要将该本机入口通过反向代理或端口转发暴露给其他人。

远程或容器部署默认不开放管理操作。如需开放，在 `deploy/server.env`（非容器服务使用 `backend/.env`）设置高强度随机 `MANUAL_IMPORT_ADMIN_TOKEN`，仅通过受保护的 HTTPS 或内部入口使用，不提交或共享令牌。默认 SQLite 位于 `data/execution_history/manual-capabilities.sqlite3`，可用 `MANUAL_IMPORT_DB` 指定，容器配置指向持久卷。

1. 点击左侧「添加元操作」打开弹窗，选择目标仪器（目前支持 VD10），上传有文字层的 PDF 并点击「生成元操作」。生成的条目仍为待审核草稿。仅远程管理模式需要输入令牌。限 10 MB、150 页。本地按受支持的任务章节和证据组织卡片，不调用模型，也不对扫描页做 OCR；缺少依据的任务不会生成。
2. 展开卡片核对输入、预期结果与各内部步骤的页码。可编辑名称、描述及内部步骤，逐条审核通过或驳回，再点击「发布本批已通过项」。已有旧版碎片需要重新上传，不能作为新任务直接发布。已发布内容不自动迁移或删除。
3. 如需查看编排效果，可逐项启用 VD10 草案预览，再选择已启用的能力生成独立预览。停用后旧预览快照不再受理新请求。

基础能力库、其他场景、原 VD10 自动编排及历史记录不变。新能力发布后仅在扩展列表展示，不允许拖拽到生产流程。草案预览不调用原自动编排、不会下发设备命令。所有导入条目均保留待实机验证和仅接口边界，审核发布不等于实机授权。

## 发布编号与撤回

目标设备下拉框包含基础仪器库和已登记的扩展设备。「新增设备」只登记名称和独立设备 ID，保存在扩展库中。当前只提供 VD10 说明书解析规则；若新增设备确实适用 VD10 说明书，选择它并勾选「批准所选设备使用此说明书」再生成。发布后条目进入所选设备的独立分组，不加入原 VD10 草案预览。

每次单条或批量发布生成独立编号（如 `R0001`），记录时间和成员；它与单项能力版本 `1.0.0` 不同。导入弹窗中的「发布历史与撤回」支持撤回一项或该次发布中仍生效的全部条目。撤回会从左侧和草案预览移除，并保留原审核内容、说明书证据和撤回时间。不影响其他发布、基础库或历史记录。旧版已发布条目按原导入批次补录，发布时间显示未登记。

本功能为撤回发布，不是任意历史快照恢复；撤回的条目不会自动复原或重新启用。

新增设备的最后一项已发布元操作被撤回后，设备会从左侧能力库和「目标设备」下拉框移除。需要再次使用时，可通过同名登记恢复设备；历史记录保留，已撤回条目不会重新发布。
